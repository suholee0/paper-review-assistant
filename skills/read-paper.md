# 원문 전체 읽기

## PDF 준비

저장소 루트에서 실행한다:

```bash
node scripts/read-paper.mjs <paperDir>
```

입력은 `<paperDir>/original.pdf`다. 결과는 `source/index.json`과 `source/pages/0001.txt` 등의 페이지별 텍스트다. index의 페이지 수, 페이지별 글자 수, 텍스트가 거의 없는 페이지를 확인한다. 추출물은 원문을 읽는 보조 자료이며 원본 PDF를 대체하지 않는다.

## 전체 범위 확인

- 모든 페이지를 작은 묶음으로 읽는다. shell 출력이 잘리면 더 작은 범위로 다시 읽는다.
- 본문 섹션, 그림·표·수식 위치, 결론, 참고문헌, 부록/보충 자료 범위를 메모한다. source/reading-notes.md에 페이지 및 섹션별 확인 결과를 남기면 긴 작업에서도 재개할 수 있다.
- HTML이 있으면 웹 도구로 열어 구조와 수식을 확인한다. 등록된 PDF와 논문 제목·버전이 같은지 비교하고 HTML에 없는 부록은 PDF에서 읽는다.
- 검색 결과나 웹 도구의 일부 발췌만으로 논문 전체를 읽었다고 판단하지 않는다.

## 이미지로 확인

```bash
node scripts/read-paper.mjs <paperDir> --render 2,4,7
```

`source/images/0002.png` 등을 현재 이미지 보기 도구로 연다. 읽기 순서가 깨진 다단 문서, 표, 그림, 수식 및 텍스트가 거의 없는 페이지를 확인한다. 스캔 PDF도 이미지로 읽을 수 있지만 읽을 수 없는 내용은 명시한다. 이 도구에는 OCR이 없다. 렌더링 경고나 누락이 있으면 해당 시각 요소를 원본 또는 동일 버전 HTML과 대조한다.

## deep read

skim에서 만든 요약만 재사용하지 말고 background 문서를 읽은 뒤 페이지별 원문을 다시 읽는다. 각 섹션의 주장·근거·가정·한계를 페이지/섹션 번호와 함께 analysis.md에 연결한다.
